In this assignment, you will design a World of Warcraft inspired Dungeon Finder system. The goal is to choose the data structure you believe is the best fit for the problem, implement the system in Python, and explain why your choice makes sense.

 

Scenario:

You have been hired by Azeroth’s Adventurer Support Team to help organize a new Dungeon Finder tool. Players are constantly signing up for dungeon groups, leaving the queue, searching for party members, and checking who is waiting.

 

Your task is to create a Dungeon Finder program that manages players waiting for a dungeon run.

 

You must choose the data structure that you think works best for this system.

 

Possible data structures include:

- Linked List

- Stack

- Queue

- Tree

- Graph

 

Program Features:

Your program must allow the user to:

 

    Add a player to the Dungeon Finder

   - Store the player’s name

   - Store their class

   - Store their role (Tank, Healer, or DPS)

 

    Remove a player from the Dungeon Finder

 

    Search for a player by name

 

    Display all players currently waiting

 

    Count how many players are currently in the Dungeon Finder

 

    Include a menu so the user can interact with the program

 

Your Job:

You must decide which data structure should be used to store the players.

 

For example:

- A queue might make sense if players should be matched in the order they joined

 

There is not always one perfect answer. What matters is that you can explain your choice clearly.

 

Written Reflection:

Along with your code, include a short explanation that answers the following questions:

 

    What data structure did you choose?
    Why did you choose it?
    What advantages does it provide for a Dungeon Finder system?
    What limitations does it have?
    Was there another data structure you considered?

 

Program Requirements:

- Write your solution in Python

- Use functions to organize your code

- Use one main data structure to store the Dungeon Finder data

- Include a working menu-driven interface

- Use clear variable names and readable code

- The program must successfully add, remove, search, count, and display players

 

Example Player Data:

- Thrall – Shaman – DPS

- Jaina – Mage – DPS

- Muradin – Warrior – Tank

- Anduin – Priest – Healer
