## What data structure did you choose?

I chose to use a singly linked list to model the dungeon finder waiting list.


## Why did you choose it?

I chose to use the linked list because I wanted to be able to send a specific 
grouping of roles into dungeon. 


## What advantages does it provide for a Dungeon Finder system?

The linked list allows for easy removal and display of players any players
at any position with built in methods. 


## What limitations does it have?

The linked list will take up more and more memory the longer it gets. It can 
also start taking quite a while to append new players to the waitlist if it 
gets rather long, longer than a queue or a stack would take I believe.


## Was there another data structure you considered?

I considered the queue at first, but then I realized I would have to make 
a new queue every time I modified the queue in some way and the linked list
seemed more ideal over all.
